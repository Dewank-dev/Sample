# Shubh Vivah Invitation Website

A static wedding invitation website built with plain HTML, CSS and vanilla JavaScript for Netlify drag-and-drop deployment.

## Start locally

From this folder, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

## Deploy on Netlify

1. Compress the folder into a zip or drag the folder contents directly into Netlify Drop.
2. Sign up or log in to keep the site live.
3. Rename the site to your preferred Netlify subdomain.
4. Upload the folder and confirm the invite loads.

## Customize details

Update the wedding text, names, dates, function details and WhatsApp contact in the `index.html` page data object and the `send.html` template text before publishing.
